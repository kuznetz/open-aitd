# Chinese (Simplified) - language-specific codepoints (hex).
# The basic set (printable ASCII) is added automatically in the code.
# WARNING: the range 4E00-9FFF contains ~20,992 characters; the font atlas will be
# very large (may approach the GPU texture limit). Narrow it down if possible.

00A0-00FF  # Latin-1 Supplement (copyright sign, middle dot, accented letters in names)
3000-303F  # CJK Symbols and Punctuation
4E00-9FFF  # CJK Unified Ideographs
FF00-FFEF  # Halfwidth and Fullwidth Forms
2013       # EN DASH
2014       # EM DASH
2018       # LEFT SINGLE QUOTATION MARK
2019       # RIGHT SINGLE QUOTATION MARK
201C       # LEFT DOUBLE QUOTATION MARK
201D       # RIGHT DOUBLE QUOTATION MARK
2026       # HORIZONTAL ELLIPSIS
